二段階で、プロットを立てる

最初にAIと話しながら設定を固め、次にそれを材料にプロットを組みます。思いついた順ではなく、読者像とテーマから筋の通った形で決めていく進め方です。

第1段階　設定を練るざっくりした方向だけ入れてコピー。AIが質問と素案で、ぼんやりした像を形にしていきます。最後に設定シートが出ます。
▶
第2段階　プロットを組む設定シートを貼ってコピー。あらすじ、選んだ型に沿った物語の組み立て、話数割り、エピソード例まで出ます。
入力の自動保存ができません。プライベートブラウズか、保存容量がいっぱいの可能性があります。下の「入力を書き出す」でファイルに控えを取ってください。

1. 書きたいものの方向

必須はジャンルと、アイデアかテーマ

2. 想定読者

ここが判断の基準になります

3. 分量

話数と節目の位置を自動計算

4. 第1段階のプロンプト

AIと話して設定を固める

コピーしてAIに貼り付けると、AIが質問と素案3つを出しながら、設定を一つずつ決めていきます。決まったら「まとめて」と伝えると設定シートが出ます。それを第2段階に貼り付けてください。

やりとりは一問一答で進みます。思いつきを足していくのではなく、読者像とテーマに照らして「それはこの読者に効くか」を確かめながら決める進め方です。

1. 設定シート

必須
貼り付けたら「下の欄に展開して練り直す」を押してください。シートの内容が下の欄に入り、直してからプロンプトを作れます。押さない場合は、シートをそのまま使い、下の欄に書いた項目だけが上書きになります。

2. 設定

展開していません

3. 登場人物

主人公＋最大10人
人物の欄を開く

書き込んだ項目だけがシートを上書きします。シートにいる人物と同じ名前を書けば、その人物の修正として扱われます。空欄のままの人物カードは無視されます。

4. 第2段階のプロンプト

プロットを出力する
承認されていないAI仮案が 0 件あります（黄色の欄）。このままコピーすると、AIには未確定の案として渡ります。
削除の指定（設定シートのこの記述は使いません）

入力の控え

任意
入力はこの端末のブラウザにのみ保存され、このアプリからどこにも送信されません。ただしコピーしたプロンプトをAIに貼り付けると、その内容は利用するAIサービスに送信されます。
